# 登录页改进与验证

登录和注册沿用 AI Radar 的现有单栏表单，补齐常用操作，不更换身份系统。

- 密码默认隐藏，可用带文字的眼睛按钮显示／隐藏；按钮支持键盘且不会提交表单。提交时重新隐藏。注册和确认密码各自有明确的控件名称。
- 登录使用 `username`／`current-password`，注册使用 `new-password`，支持浏览器密码管理器、自动填充和粘贴。浏览器是否弹出保存密码由浏览器及用户设置决定，项目不保存、回填明文密码。
- 大写锁定时显示提醒；注册密码不一致时聚焦确认框，邮箱和输入错误提供已有明确反馈。提交中禁用重复操作。
- “保持登录，最长 7 天”默认不勾选。普通登录保持原有短期、当前标签的机制；勾选后仅持久保存有期限的登录凭证。普通用户期限为 7 天，管理员和审核用户不延长原短期权限。
- 记住的凭证对应服务器会话记录，退出时撤销该次凭证并清理本地存储，其他标签同步退出。账户停用、角色改变、会话到期或撤销都不继续授权；其他设备的独立登录不被此退出误撤销。
- 浏览器禁用持久存储时回退为当前标签会话。项目不会保存明文密码。遗失密码的邮箱重置链路尚未提供，因此没有添加伪装成已可用的邮箱重置入口。

参考 [GitHub 登录页](https://github.com/login) 的单一主操作与独立注册入口，以及 [GOV.UK 密码输入规范](https://design-system.service.gov.uk/components/password-input/) 的显示开关、自动填充、粘贴和大写／拼写处理。是否增加 SSO、验证码或找回邮件取决于实际服务配置，不作为装饰入口添加。

## 数据与发布范围

新增 `remembered_sessions` 表，仅记录随机会话编号、用户编号、到期时间和撤销时间，不记录密码或原始凭证。迁移版本 `20261015_0027` 只增表及索引，既有账户、研究和试用数据不重写。旧登录请求兼容，`rememberMe` 默认为 `false`。

现有部署先运行 `alembic upgrade head` 再启动新服务。若需回退到不支持会话撤销的旧服务版本，应先作废此版本签发的记住登录凭证，例如轮换 JWT 签名密钥；旧服务不能兑现新的服务器撤销语义。此操作会使既有会话重新登录，需要单独安排，当前未执行。

# 自动批量 API 试测

适用于你能实际访问的模型 API。相同实际样本、提示、输出上限及判定标准依次请求所选 1–3 个入口，再导入当前分析。只有一个入口也能验证自身任务；两个 API 型号的比较不能当成两个 IDE 产品的效果比较。

网页不收集 API 密钥、不代你购买入口，也不自动发送材料。执行器在你自己的电脑运行；未经执行确认默认只预览。当前支持 Messages 与 Chat Completions 两种协议。协议不能证明网关底层模型身份，返回型号不同会停止。

## 1. 在助手中准备

在模型 API 分析中准备所选候选的试用记录，展开“自动批量 API 试测（本地运行）”。默认逐条填写输入材料、应该返回的字段及正确值，选择文字、数字、是／否、空值或嵌套 JSON；已有样本文件时可切换“粘贴 JSON”。例如编号 `001` 应保留为文字，数字 `0`、布尔 `false` 与空值 `null` 分别核对。空白样本、重复字段和无效数字不能导出，不自动补造正确答案。

检查处理要求、最少合格样本数、预计费用上限及币种，然后下载运行文件。草稿按账户和分析记录保留在当前标签页，切换填写方式、试用步骤及刷新可以恢复；退出登录时清除，关闭标签页后不保证保留。存储不可用时页面会提示；需要长期保留时下载文件。网页不向服务器上传这些原始材料，普通试用摘要仍沿用私人保存流程。

逐个样本检查全部 JSON 字段和值，不采用模型给自己的评分。适合固定字段抽取及可明确标注的任务；开放写作、完整 IDE 编辑与任意代码测试不能由这一检查替代。

## 2. 本地配置并预览

在已安装后端依赖的项目 `app/backend` 目录中运行，PowerShell 示例（替换实际文件路径）：

```powershell
python -m app.decision_trial_runner --plan "C:/path/my-api-trial.json" --setup-targets
```

交互填写各候选实际账户的模型标识、完整 HTTPS API 地址、协议、每百万输入/输出单价和密钥环境变量名。生成的同名 `.targets.json` 仅含入口与变量名，不含密钥；已有文件不覆盖。地址和型号从你实际账户确认，不根据展示名称猜测。

该命令只显示预计请求数、按自填单价计算的保守估算及费用上限是否足够，没有模型调用。币种须与本批一致；网关美元标记额度不能直接当作现金美元。缺少报价先核对，不填“0”冒充免费。

## 3. 明确确认后执行

```powershell
python -m app.decision_trial_runner --plan "C:/path/my-api-trial.json" --execute --accept-data-transfer --prompt-for-keys --output "C:/path/private-trial-run-01"
```

两个执行标志表示你允许将该文件中的输入发送至已配置入口并承担相关费用。密钥在本地隐藏提示中输入，不写文件；也可事先在本机安全环境配置所填的环境变量。

上限为 20 个样本、3 个入口；网页导出默认 120 秒、每次最多 4096 输出 token。自填单价和用量计算均是估算，不是供应商账单或供应商强制扣费上限。缓存额外计费未配置、用量缺失、超限、截断、型号不符、拒绝或网络失败会保留回执并停止后续请求，不自动换供应商或重试。实际质量不合格会记作失败样本，继续完成同批剩余样本。

输出目录必须是新的；发送前先写回执，避免中断后悄悄重复付费。中断后的费用保留预留估算。不要删除旧记录再原样重跑；先核对真实已发送请求、剩余样本与账户费用，再决定新一轮。

## 4. 回填当前分析

在网页选择输出目录内的 `receipt.json`，检查候选、样本批次、版本、成功/失败及中断状态，再点击“回填到本页草稿”。已有结果受到保护，只有明确勾选替换才覆盖本批效果、时延、费用记录；条款及其他候选保留。最后点击原有“保存结果，更新判断”。

回执包含实际输入、标注和输出，应当留在私人位置。网页仅将试用摘要及指标回填既有私人记录，原始回执不作为公开事实上传。它仍是用户提供的记录，不是加密证明或独立审计。

费用继续标记为估算，时延是否达到业务要求、实际扣费和数据条款保持待核对；导入不自动生成主选结论。即使某 API 全部样本通过，也只支持该批样本、具体入口和配置的限定判断。

## 工程验证边界

单元测试使用显式合成的 HTTP MockTransport，覆盖两种协议、同样本、失败停止、费用预留、密钥不落盘及导入保护。这些测试不是实际供应商业务成绩。本轮没有新增付费模型调用。

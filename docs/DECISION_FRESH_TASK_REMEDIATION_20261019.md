## 实现

- 共享场景目录增加“材料/对象 + 操作 + 输出形式”的组合规则，前后端读取同一份规则；不是加入八道完整问题字符串。
- 服务端提取任务材料、原始限制和时间范围；否定技能描述不会变成输入材料。该解析仍是有边界的确定性实现，不宣称无限制自然语言理解。
- 完全断网进入实际部署约束检查；与云部署冲突时拒绝静默放宽。合同操作不明确时只追问查询条款还是字段抽取，保留离线等条件。
- 识别中文数字月预算及原厂渠道要求；预算选项不能高于原题明确上限。已有每日调用量和每次 token 数时，仅追问月运行日；选择后计算月用量，不默认为30天、不推断汇率、不将未知费用当免费。
- 视频延长、人物一致等任务明确标为支持范围外，不返回不相关的问答/文字方向。
- 编码计划只围绕用户指定的一项任务，保留时间上限、审批和禁止事项；完整报告与试用包共用服务端计划，试用提示包含执行范围与时间限制，未执行结果保持 `executed=false`。

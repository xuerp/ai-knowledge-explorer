## 配置与数据范围

使用 backend/.env.example 中的 AI_RADAR_DECISION_INTERPRETATION_* 独立配置：ENABLED、API_URL、API_KEY、MODEL、BUDGET_ID、MAX_CALLS、USER_IDS。只有明确启用、连接完整、总限额为 1–100 且授权账户列表非空时可构造解释器。采集接口凭据不会自动复用，其他账户保持原默认路径。

仅将本次题干、补充备注和澄清选择发送给指定连接；不发送账户 ID、业务文件、用户历史记录或供应商审计数据。题干组合最多 8192 UTF-8 字节，完整结构请求最多 32768 字节；每次输出参数保持 4096 token、low、最长 80 秒。没有重试、重定向或模型切换。返回模型必须与所选模型一致，用量需完整自洽；超出约定 token 边界后停止后续调用。

## 限额与恢复

- 总限额没有每日或进程重启后的自动补充。预算 ID 与连接、模型、授权账户及上限绑定，同一 ID 的配置变化不能重置或提高额度。
- PostgreSQL/SQLite 在调用前原子预留并提交一次，单预算仅允许一个在途请求。并发未获预留的请求不调用供应商；预留后的失败或超时不退回次数。
- 网络失败、用量不明、错误模型或无效解释关闭预算。进程中断留下的在途记录保持关闭，不自动重复扣费。
- 审计只保存题干指纹、预算、状态与脱敏用量，不保存题干、密钥、完整端点或供应商错误正文。实际题干仍按既有私密研究权限保存。
- 管理诊断为 GET /api/v2/admin/decision-interpretation，沿用现有管理员鉴权并设置 no-store；提供已用/剩余次数、阻断与在途状态，不提供凭据。
- 授权账户可通过 GET /api/v2/decision-interpretation 查看本配置的已用/剩余次数与停止状态；未授权账户只得到 enabled=false，匿名请求被拒绝。此接口不返回预算标识、账户列表、连接或凭据。
- 回滚先设置 ENABLED=false，保留已用限额。迁移 0028 拒绝删除有已用次数的预算，避免正常回滚抹掉扣费记录。

这是调用次数和请求规模控制，不是经价格核实的金额预算。当前网关单价及完整账单仍未核实。

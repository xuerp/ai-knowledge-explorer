# ADR-0003：Candidate 与 Verified Claim 分离

- 状态：接受
- 日期：2026-08-31
- 决策者：项目所有者与执行 Agent

## 背景

LLM 抽取结果可能包含非法结构、实体歧义、重复、冲突或缺少证据锚点。若直接写入公共知识库，一次概率性错误会传播到时间线、对比、图谱和研究回答。

## 决策

模型输出只进入私有 Review Candidate。公共快照只读取已批准 Claim；拒绝、待审和需补证据状态不会泄露到公共目录。审核决定记录状态、版本、时间、审核人、分类与备注；发布历史与审计日志独立保留。

## 后果

- 数据生产与公开读取可以独立演进。
- 审核增加发布延迟，但建立了可追溯信任边界。
- 并发决定使用 `status + version` 原子抢占；相反决定只有一个终态赢家。

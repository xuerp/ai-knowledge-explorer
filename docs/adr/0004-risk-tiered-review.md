# ADR-0004：按风险分层审核，不以统一阈值自动批准

- 状态：接受
- 日期：2026-08-31
- 决策者：项目所有者与执行 Agent

## 背景

官方来源并不自动等于低风险。价格、可用性、Benchmark、安全事件和冲突更新的错误代价高于普通产品描述；统一置信度阈值无法表达这种差异。

## 决策

审核队列按证据完整性、冲突、来源、时效与谓词风险分层。批量批准只接受有直接原文锚点、无冲突的安全候选；高风险与生命周期更新逐条处理。自动批准必须等待真实人工样本证明精度，并保留抽检，不能因积压降低门槛。

## 后果

- 高风险内容吞吐更低，但错误不会因批量操作扩散。
- 批量事务任一项失败时整体回滚。
- 审核可观测性统计 category + optional note，历史分类未知时明确显示 `uncategorized`。

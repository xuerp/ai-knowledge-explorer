# ADR-0006：关系缺口不是 KPI

- 状态：接受
- 日期：2026-09-01
- 决策者：项目所有者与执行 Agent

## 背景

质量报告以“核心实体至少 5 条可解释关系”计算覆盖差值。把这个差值当作交付配额，会诱导从实体两两组合或模型常识制造边，与 AI Radar 的证据优先原则冲突。

## 决策

覆盖差值只用于发现值得继续采集的实体和关系类型。新增关系必须来自已保存的官方 Evidence/Snapshot、合法本体谓词和人工审核；不存在证据时允许指标不提升，并明确记录阻塞原因。

## 证据

Epic 2A 真实诊断得到 19 个核心实体、16 个低覆盖实体、覆盖差值 44，以及 181 条尚未被关系引用的官方 Evidence。首批新增 URL 因安全 DNS 校验未形成 Snapshot，所以关系数保持 76；没有为了缩小 44 的数字绕过安全策略。

## 后果

- Case Study 可以解释为什么指标未变，而不是伪造优化曲线。
- 关系工作清单以 Evidence 可用性排序，不以任意实体对排序。
- 未来阈值变化必须作为质量规则版本变更记录，不能回写历史结果。

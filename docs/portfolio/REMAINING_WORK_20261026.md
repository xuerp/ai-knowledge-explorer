# 作品集收尾范围与工时估算

当前估算为 12–24 小时有效工作量，建议安排 2–4 个工作日。它是排期区间，不是完成承诺，也不是后台持续执行的保证。发现新增事实冲突、外部来源不可访问或部署问题时，需要据实际证据更新。

| 工作 | 估算 | 完成条件 |
| --- | --- | --- |
| 来源与语义核实、引用类型和派生字段修复 | 8–16 小时 | 保留完整目录；事实明确关联来源、对象、日期和条件；无法证实的内容明确标记，不冒充已核实 |
| 同一候选版本跨页与账户流程复验 | 3–5 小时 | 动态筛选、知识库、家族、图谱、研究、关注及站内通知的规定路线有实际回执；修复发现的问题 |
| README/展示同步及部署后复验 | 1–3 小时 | 展示版本可追溯到 GitHub 提交；实际网址核心流程可用；未测试的外部服务不写成已验证 |

## 当前核实队列

683 条来源记录按去除片段后的 URL 合并为 339 个网址；252 个网址存在至少一个获取或摘录待处理项。这是核实单位，不是错误事实数量。即便摘录精确匹配，也仍需核对语义和时效。

队列由 `backend/scripts/build_source_review_queue.py` 生成，追踪 Claim 与其他嵌套数据引用，优先核对影响事实最多的页面。完整私有工作产物在 `artifacts/full-catalog-verification-20261025/semantic-review-queue.json`。

首批对照 [Google 官方更新日志](https://ai.google.dev/gemini-api/docs/changelog)，确认八项既有历史事件陈述与相应日期、适用范围相符，记录见 [语义复核清单](SEMANTIC_REVIEW_20261026.json)。这是历史公告语义核对，不表示相关模型现在都可用，也没有把原有整理摘要改称逐字引语。

随后修复采样参数的指代及型号范围，关联直接官方指南，同步事实、时间线和动态详情。Deep Research 的时态已在本地 API 快照纠正为历史发布；该条记录不在干净仓库目录中。两项本地 API 回读通过，动态页桌面及 390px 手机视口检查通过（375/375，无横向溢出），新增三项来源审计／目录回归通过。完整目录保留 262 实体、462 条事实、259 条动态；新增指南后本地来源共 684 条。此前 683 条来源的审计表属于修正前基线，不能当成当前全量复核结果。

不扩展产品范围，不删除目录来降低核实数量，不加入虚构演示结果。真实付费调用、邮件实际投递等未执行项仍如实单列。

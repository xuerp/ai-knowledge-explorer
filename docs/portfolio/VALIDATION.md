## 五场景软件走查

2026-11-01 使用实际发布快照，在关闭外部模型和邮件的隔离环境中检查文档问答、仓库工具、私有部署、JSON 抽取与办公新手五个场景。保留原题、失败结果和未知项，检查保存重开、澄清与旧版保留、来源入口、任务复制、报告下载及 1280px / 390px 页面。文档问答导出的四页 PDF 已检查排版。

走查发现并修复三类问题：引用跳到不存在的页内位置；用户选择写作方向后被原题中的编程背景词带偏；手机操作资料横排过窄。私有部署仍不能确认合格候选，页面改为明确说明部署依据缺口及核验步骤，没有补造型号资格。以上属于软件与启发式检查，参与真人数为零，未执行所推荐工具的业务试用，也未测量完成率、满意度或效果排名；对应版本的 CI 和线上发布另行判断。

同日用普通用户账号完成新网址五场景提交与保存重开、原题及条件恢复、新手澄清与旧版保留，并检查 1280px / 390px 报告。文档问答核对来源、前台复制和实际 Markdown/PDF 下载，下载的四页 PDF 逐页检查。首次在原标签复制失败，页面提供手动选择复制且已验证；新打开的前台标签复制成功。失败原因未独立确认，两次结果均保留。

线上首次跳转另复现更新前 CSS 地址返回 404。资源加载错误增加一次自动刷新恢复、五分钟内防循环和明确的手动刷新入口；普通业务错误不自动刷新。使用真实错误组件做隔离受控重放，确认自动与手动刷新后测试会话和草稿保留，桌面与手机错误页均检查；这项受控重放与线上现场故障分别记录。

- 后端按领域拆分 11 个路由模块，`main.py` 仅负责应用组装；拆分前后的完整 OpenAPI 描述一致。修正退出接口的相对导入后，完整本地回归为 1146 项通过、8 项跳过。
- 审核路由、状态恢复、六组操作与各业务面板分离；历史种子按领域拆分，原导出接口和种子内容保持一致。前端完整检查为 338 项通过，含类型、布局约束及构建。
- 配置 API 的预发布构建不包含离线快照块；共享 `index` JS 的本地构建大小从 2,649,358 字节降至 363,950 字节，本地 gzip 从 467,098 降至 113,586 字节。这是构建产物对比，不是线上传输测速，也未缩减完整目录。
- 隔离本地账户实际检查审核登录、来源筛选及退出；桌面 1280px、手机 390px 检查审核、首页、知识库、对比、助手和模型详情。所检查页面的 `scrollWidth` 与 `clientWidth` 一致。主动中断本地 API 后，首页显示明确错误，没有替换成旧示例事实。
- 当前测试基线保留原路径，临时回执写入 `artifacts/`；历史实施记录通过 Git 历史查询。公开 `.env.staging` 保留两个非敏感网址，并增加字段和 URL 内容检查。

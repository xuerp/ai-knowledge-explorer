# 运行与演示完整项目

按[项目 README](../../README.md#运行完整项目)安装依赖并启动前后端。未配置 API 时可浏览完整历史目录；登录、研究与保存需要后端。先核对所用版本，GitHub 更新不代表预发布网站已同步部署。

## 建议演示路线

| 步骤 | 页面                  | 展示重点                                 |
| ---- | --------------------- | ---------------------------------------- |
| 1    | 首页与动态 `/updates` | 完整模型家族、变化列表、筛选和详情跳转   |
| 2    | 知识库 `/knowledge`   | 对象分类、家族与版本关系                 |
| 3    | 模型详情              | 规格、版本状态、来源链接和已有原文摘录   |
| 4    | 对比 `/compare`       | 同一维度下的已知条件和未知信息           |
| 5    | 决策助手 `/ask`       | 输入自己的任务与限制，登录后发起实际研究 |
| 6    | 研究记录              | 保存后重开、追溯引用与导出实际结果       |
| 7    | 图谱 `/graph`         | 从实体关系回到对象与证据                 |

首页问题是输入示例，不是已有研究成果。未登录提交保留任务并引导登录。不要用预写答案、模拟用户活动或测试数据冒充真实研究结果。

## 演示前检查

- 前后端可访问，API 配置指向预期环境；已有数据库保留，不用种子覆盖个人记录。
- 对要展示的事实打开直接来源，核对时点、条件和适用版本。无法确认的内容明确说明。
- 如果展示保存和导出，实际执行后再说明成功；不要只凭按钮存在宣称流程已通过。
- 实际模型调用遵守现有费用与授权限制。无模型调用时准确说明使用的是检索与提取流程。

[当前检查范围与剩余问题](CATALOG_VERIFICATION_20261026.md)是演示边界。`real-data/` 中的 Dify / LangChain 小样本仅为历史来源校验资料，不用于替代完整应用。

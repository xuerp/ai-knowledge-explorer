| 步骤 | 页面                  | 展示重点                                 |
| ---- | --------------------- | ---------------------------------------- |
| 1    | 首页与动态 `/updates` | 完整模型家族、变化列表、筛选和详情跳转   |
| 2    | 知识库 `/knowledge`   | 对象分类、家族与版本关系                 |

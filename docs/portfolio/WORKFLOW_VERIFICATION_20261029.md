## 已实际验证

| 操作       | 结果                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |

| Markdown   | 浏览器实际下载，包含任务、条件、功能比较、执行说明和来源                                   |

| 退出       | 返回登录表单；原令牌再次访问账户接口返回 401                                               |
| 私密边界   | 匿名访问研究接口返回 401，页面显示重新登录入口                                             |

账户级模型解析返回 `enabled=false`。本轮使用已有知识与结构化逻辑，没有付费模型调用，没有执行候选编码工具，也没有发布测试研究的公开分享链接。

## 本轮发现与修复

线上 Linux 使用未嵌入的标准中文 CID 字体，PDF 阅读器会自行替换，英文名称出现异常字距。改为随服务分发并嵌入 SIL OFL 许可的 Noto Sans SC 子集，统一中文与英文度量。本地样张已渲染确认，报告的四项回归通过；修复后的线上 PDF 仍需在对应版本发布后重新下载确认。
